# 02 — Data Source Matrix

Data-type legend: **Official** = first-party API/owned data · **Inferred** = modeled/estimated by a third party · **Scraped** = extracted from public pages (ToS-sensitive) · **Anecdotal** = individual opinions/comments.

Confidence legend: ⭐⭐⭐ strong / structured / first-party · ⭐⭐ directional / third-party modeled · ⭐ weak / anecdotal / single-source.

## Cross-source reading rules

- **Never blend types silently.** A TikTok ad keyword and a Google Ads search volume are different universes — keep the `data_type` label on every row.
- **Trends and TikTok answer "relative/which", Google Ads answers "how much" (roughly), GBP answers "what really triggered a real profile".** Use them for different questions.
- **N=1–5 GBP is a worked example, not a market.** Any generalization from the pilot must be labeled ⭐ and flagged by the Skeptic agent.
- **Spanish-first.** Always run MX/es localization; capture `reseñas / opiniones / calificaciones / reviews` as distinct variants and let the data say which dominates — don't assume.
